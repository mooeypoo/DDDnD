# What is the catalog?

::: warning Designer Desk
This is the x-ray of content **currently in play**, not How to Play. Player rules: [The table](/guide/gameplay).
:::

The catalog is generated from the base pack and the tutorial pack. It is a reflection of authored JSON, not a hand-written wiki.

## Playable-latest

Each entity page shows the version current entry-point adventures (and tutorials) actually reference. If two files share an id, the desk shows the one on the table.

Retired files can sit in a small **Earlier files** fold on the detail page. That is history, not the live load.

## What you can see here that players cannot

- Versioned linkages
- Aftershock wiring
- Starting vials and authored turn caps
- Raw JSON

That transparency is for designers. The game still hides the wiring.

## How to use this section

1. Adventures — playable scenarios and tutorials
2. Cards — effects and aftershock refs
3. Aftershocks — delayed score changes
4. Stakeholders — reaction-rule structure
5. Events — pressure and effect chains

If a run feels odd, this is usually the fastest way to see whether the pack in play is the pack you think it is.
